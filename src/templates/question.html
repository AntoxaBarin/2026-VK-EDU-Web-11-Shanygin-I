How to properly use virtual environments in Python?

I'm just starting to learn Python and heard about virtual environments. Why are they needed and how to use them properly? What are the best practices?

I tried using venv, but don't fully understand when to create a new environment and when I can use an existing one. Also interested in how to properly manage dependencies in a project.

Virtual environments in Python are isolated environments for installing packages. They help avoid conflicts between dependencies of different projects.

Basic commands:

python -m venv myenv
source myenv/bin/activate  # for Linux/Mac
myenv\Scripts\activate.bat  # for Windows
pip install package_name
pip freeze > requirements.txt

I recommend creating a new environment for each project. This is the best practice!

An alternative to venv is poetry or pipenv. They provide a more convenient interface for managing dependencies and virtual environments.

Poetry automatically creates and manages the virtual environment, and also allows you to easily separate production and development dependencies.
